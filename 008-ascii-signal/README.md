# 审美分享-08：ASCII Signal · 图片转字符画

> 2026-08

## 适用于

想把一张照片、海报或图形变成可复制的字符画，又不想上传素材或安装软件时。

## 这次做的是什么

`ASCII Signal` 是一个纯浏览器端的图片转 ASCII Art 工具：它不“识别人脸”或调用 AI，而是先将图片缩成字符网格，再按每个网格的亮度挑选字符。亮处使用稀疏字符，暗处使用密集字符，因此输出是真实文本，可以直接复制到 README、终端或聊天工具。

## 拿走即用

本期类型：**离线代码模板**

双击打开 [template/index.html](template/index.html)，拖入一张图片即可使用。可调字符宽度、对比、细节扰动、反相和字符表；可在“彩色”（逐字符保留原图 RGB）与“黑白”之间切换，背景可在纯白与纯黑之间切换。支持复制 `.txt`、下载 `.txt` 与导出 PNG。所有图像处理都在你的浏览器内完成。

## 复刻笔记

- 输出宽度控制细节量；108 列适合普通照片，60–80 列适合聊天或 README，160 列以上适合海报级 PNG。
- 字符的宽高比例不是 1:1，转换时将行数按约 `0.52` 倍修正，避免图像被拉长。
- 默认字符表按“暗 → 亮”排序；自定义字符表也遵循这个顺序。
- GIF 会读取第一帧；动态图像留到下一版处理。
